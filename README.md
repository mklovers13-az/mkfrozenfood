# MK Frozen Food — Starter App

A working browser prototype for MK Frozen Food, Karachi.

Included:
- Product catalog
- Categories/search
- Cart
- Checkout
- Delivery location picker (browser GPS + map pin)
- COD / Cash / Online payment choices
- Order confirmation
- WhatsApp-ready order message without displaying the business WhatsApp number

Important:
This is a frontend prototype. Real online payments, persistent database, WhatsApp Business API, authentication, admin/rider accounts and production hosting still need backend/provider credentials and deployment.
